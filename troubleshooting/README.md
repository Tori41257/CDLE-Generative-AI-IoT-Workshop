# トラブルシューティング

## デバイスが認識されない

- USBケーブルを抜き差しする
- 充電専用ではなく、データ通信対応のUSBケーブルを使用する
- 別のUSBポートを試す
- 開発環境で正しいシリアルポートが選ばれているか確認する

## ビルドに失敗する

- エラーメッセージの最初と最後だけでなく、全文を確認する
- `platformio.ini` のボード指定とライブラリ設定を確認する
- コードが対象機種「M5Stack CoreS3 SE」向けになっているか確認する
- 生成AIへ、エラー全文・コード全文・使用機材をまとめて伝える

## 転送に失敗する

- シリアルモニターを閉じてから再実行する
- 正しいポートが選択されているか確認する
- USBケーブルと接続を確認する
- M5Stackを再起動して再度転送する

## Chain Encoderの値が変わらない

- GROVEケーブルが奥まで差し込まれているか確認する
- 使用しているポートとコード上の設定が一致しているか確認する
- 回転軸とエンコーダーが確実に連動しているか確認する
- エンコーダー単体を手で回し、値が変化するか確認する

## 通知音が鳴らない

- スピーカーの初期化処理を確認する
- 音量設定が小さすぎないか確認する
- 停止判定時間が経過しているか確認する
- まず短いテスト音だけを鳴らすコードで動作確認する

## 生成AIへ相談するとき

以下をまとめて伝えると、原因を特定しやすくなります。

- 使用機材と接続方法
- 開発環境
- 期待する動作
- 実際の動作
- エラーメッセージ全文
- 現在のコード全文
- すでに試したこと
