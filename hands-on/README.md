# ハンズオン：チョコ停検知デバイス

生成AIの支援を受けながら、模擬製造ラインの回転停止を検知して通知するIoTデバイスを作ります。

## 要件

- Chain Encoderの回転を読み取る
- 回転中と停止中を判定する
- 一定時間停止が続いたら通知音を鳴らす
- 停止判定後も、回転が再開したら通常状態へ戻る

## 基本手順

1. M5Stack Core2とChain EncoderをGROVEケーブルで接続する
2. Chain Encoderと模擬製造ラインの回転軸をブロックで接続する
3. 使用機材と要件を生成AIへ伝える
4. 生成されたコードを開発環境へ貼り付ける
5. ビルドしてM5Stackへ転送する
6. 回転中・停止中の動作を確認する
7. エラーや期待と異なる動作を生成AIへ伝える
8. 修正したコードを再転送する

## 完了条件

- 回転している間は停止通知が発生しない
- 回転を止めると、設定時間後に通知音が鳴る
- 回転を再開すると通常状態へ復帰する

## 追加機能の例

- 稼働中は緑、停止中は赤で画面表示する
- 停止までの秒数を画面に表示する
- 停止判定時間を変更できるようにする
- 停止回数や累積停止時間を記録する
- Wi-Fi経由で停止情報を送信する
- Chain ToFで距離や物体の接近を検知する

困った場合は [トラブルシューティング](../troubleshooting/README.md) を参照してください。
