# CDLE Generative AI IoT Workshop

生成AIを活用し、未経験から製造現場IoTのプロトタイプ開発に挑戦するCDLEワークショップの資料リポジトリです。

## テーマ

**未経験から始める製造現場IoT  
— 生成AIを使ってチョコ停検知デバイスを作ってみよう —**

このワークショップは、プログラミングそのものを学ぶ講座ではありません。  
生成AIとの対話を通じてアイデアを言葉にし、プログラムを生成し、実機で試し、エラーを手掛かりに改善する体験を目的としています。

> 新しい技術への挑戦は、生成AIで身近になる。

## 対象

- 製造業で、これから業務にデータやAIを活用したい方
- IoTやプログラミングに興味はあるものの、何から始めればよいか迷っている方
- 生成AIを業務改善やDX推進に活用するイメージをつかみたい方

## ゴール

- 生成AIを使えば、知らない技術にも着手できることを体感する
- 「対話する → 試す → 直す」という開発サイクルを経験する
- 現場の困りごとを、動くプロトタイプへ変える第一歩を踏み出す

## ワークショップの流れ

| セクション | 内容 |

| 1. オープニング | JDLA・CDLEの紹介 |

## 生成AIとの付き合い方

1. **対話する**  
   曖昧なアイデアや要件を言葉にします。
2. **試す**  
   生成されたプログラムを実機へ転送して動作を確認します。
3. **直す**  
   エラーや期待と異なる動作を生成AIへ伝え、改善を繰り返します。

生成AIは「一発で正解を出す道具」ではありません。対話と試行錯誤を重ねるためのパートナーとして活用します。

Chain EncoderとChain ToFはUARTで数珠つなぎにします。Core2のHY2.0-4P端子は、このワークショップでは黄線（GPIO32）をTX、白線（GPIO33）をRXとして使用します。

## 冒頭デモ

M5Stack Core2の画面をタッチするたびに、稼働状態の表示が切り替わるプログラムを動かします。参加者はプログラムの音量設定を変更し、実機へ転送して変化を確認します。

冒頭デモで使用する見本コード：

- [このリポジトリ内のM5Stack Core2タッチデモ](demo/M5Stack-Core2-Touch-Demo)

ハンズオンの完成見本：

- [M5Stack-Core2-Chain-Monitor](https://github.com/Tori41257/M5Stack-Core2-Chain-Monitor)

## ハンズオン課題

Chain Encoderと模擬製造ラインの回転軸を接続し、次の要件を満たすチョコ停検知デバイスを作ります。

1. エンコーダーの回転を取得する
2. 回転が止まったことを検知する
3. 一定時間停止したら通知音を鳴らす
4. 生成AIと相談しながら、必要に応じて機能を改善する

進め方の詳細は [hands-on/README.md](hands-on/README.md) を参照してください。

## 発展アイデア

- 画面の色やメッセージで設備状態を表示する
- 停止判定時間や通知音量を変更できるようにする
- センサーやアクチュエーターを追加する
- Wi-Fi経由で稼働データを送信する
- APIと連携して通知や記録を行う
- データを保存し、停止傾向を可視化する
- カメラやAIを使って状態を判定する

## 注意事項

- 生成AIが出力したコードは、内容を確認してから使用してください。
- 配線や使用するGPIOは、実機の仕様と使用ライブラリに合わせて確認してください。
- エラーが発生した場合は、メッセージを省略せず生成AIへ共有すると原因を特定しやすくなります。
- 通知音を試す際は、周囲に配慮して音量を調整してください。
